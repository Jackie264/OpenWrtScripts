## Markdown style

- Blank line before and after every heading, list, table, and fenced code block
- Every fenced code block has a language tag (```bash, ```text if unknown)
- One H1 at the top, no skipped heading levels
- Use `-` for bullets, `1.` for all ordered items
- No bold-only lines used as pseudo-headings — use real headings
- No trailing whitespace; single trailing newline at EOF
- No consecutive blank lines
